# 🛒 Super Market Sales Dashboard

## 📊 Project Overview

An interactive Super Market Sales Dashboard developed using Microsoft Power BI.

The dashboard analyzes sales performance, gross income, product lines, payment methods, customer demographics, product ratings, and city-level performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Modeling
- Data Visualization

## 📈 Dashboard Features

### KPI Analysis
- Total Gross Income
- Total Quantity
- Average Rating

### Sales Analysis
- Gross Income by City
- Product Line Performance
- Gross Income by Gender
- Average Unit Price by Product Line

### Customer Analysis
- Gender-wise Gross Income
- Payment Method Analysis
- City-wise Performance

### Product Analysis
- Product Line Revenue
- Average Rating by Product Line
- Product Line Pricing

## 🎛️ Interactive Filters

- City
- Product Line
